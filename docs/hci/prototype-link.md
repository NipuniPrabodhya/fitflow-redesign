\# FitFlow Prototype Information



\## Prototype Overview



The FitFlow clickable low-fidelity prototype was developed in Figma during Lab Exercise 03.



The prototype focuses on:



\- Navigation

\- Feature discoverability

\- User flow

\- AI workout interaction

\- Progress tracking

\- Nutrition logging

\- Community participation

\- Privacy awareness



\## Main Prototype Screens



The prototype contains:



\- Home Dashboard

\- AI Workout Planner

\- AI Workout Recommendation / Daily Flow

\- Exercise Replacement

\- Workout Session

\- Progress Tracking

\- Community Feed

\- Challenge Details

\- Joined Challenge

\- Nutrition Logger

\- Food Recognition Confirmation



\## Main Prototype Flow



\### Workout



Home Dashboard  

→ AI Workout Planner  

→ Generate Workout  

→ Daily Flow  

→ Start Workout  

→ Workout Session  

→ Progress Dashboard



\### Nutrition



Home Dashboard  

→ Nutrition Logger  

→ Scan Food  

→ Food Recognition  

→ Confirm and Save



\### Community



Home Dashboard  

→ Community Feed  

→ Challenge Details  

→ Join Challenge



\### Progress



Home Dashboard  

→ Progress Dashboard

\## Selected Design Direction



The selected design was:



\*\*Variant C – AI Daily Flow Dashboard\*\*



This design places the AI-personalized workout recommendation at the top of the Home Dashboard.



The design also provides:



\- Why This Workout?

\- Edit controls

\- Replace Exercise

\- Start Workout

\- Progress summaries

\- Nutrition access

\- Community access

\- Persistent bottom navigation
